# 🎂 Birthday Coding Wish

A ready-to-run birthday website combining a hacker-style terminal, loading animation, birthday reveal and photo memories.

## Your only work

### 1. Change the name
Open `script.js` and change:

```js
const name = "YOUR NAME";
```

to the birthday person's name.

### 2. Add photos
Open the `photos` folder and replace:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`

Keep the same filenames.

You can use JPG, PNG or WEBP, but if you change the extension, also change it in `index.html`.

## Run in VS Code

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Replace the photos.
4. Open `index.html` in a browser.

Recommended: install the **Live Server** extension in VS Code, then right-click `index.html` → **Open with Live Server**.

## GitHub Pages

Upload the project to a GitHub repository.

Then go to:

Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

GitHub will give you a shareable website link.

## Personalization

Everything is already working. You can later change the final message inside `index.html` if you want.
